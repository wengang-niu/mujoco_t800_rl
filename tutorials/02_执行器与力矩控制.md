## 2.3 `data.ctrl` 不是目标角

T800 的 actuator 定义类似：

```xml
<motor name="motor_J03_KNEE_PITCH_L"
       joint="J03_KNEE_PITCH_L"
       gear="1"
       ctrllimited="true"
       ctrlrange="-415 415"/>
```

这里使用的是 MuJoCo `<motor>`。在 `gear="1"` 的简单 hinge 传动下：

```text
data.ctrl[actuator_id]  → actuator 输入 → 关节力矩
```

因此：

```python
data.ctrl[actuator_id] = 0.5
```

表示施加约 0.5 N·m 的力矩输入，**不是**把关节移动到 0.5 rad。目标角控制必须由我们读取当前角度后，通过 P/PD/PID 公式计算力矩；下一章会实现它。

## 2.4 为什么先做单关节模型

直接从 T800 开始会同时遇到：

- 25 个驱动关节；
- 自由基座；
- 重力；
- 地面接触；
- 自碰撞与关节限位；
- 全身耦合。

这不利于分辨“力矩方向不对”和“机器人因未平衡而跌倒”。所以本章先使用只有一个 hinge 的模型。

## 2.5 完整模型：单关节摆

将下面 XML 手动复制为 `/tmp/single_hinge.xml`。它不会写入仓库。

```xml
<mujoco model="single_hinge_tutorial">
  <compiler angle="radian" autolimits="true"/>
  <option timestep="0.002" integrator="implicitfast" gravity="0 0 -9.81"/>

  <worldbody>
    <light pos="0 -2 2"/>
    <body name="pendulum" pos="0 0 1">
      <!-- 绕 y 轴转动；质心位于转轴下方，因此重力会形成恢复/扰动力矩。 -->
      <joint name="hinge" type="hinge" axis="0 1 0"
             range="-1.5 1.5" damping="0.05"/>
      <geom name="rod" type="capsule" fromto="0 0 0 0 0 -0.5"
            size="0.035" mass="1.0" rgba="0.2 0.55 0.9 1"/>
    </body>
  </worldbody>

  <actuator>
    <motor name="hinge_motor" joint="hinge" gear="1"
           ctrllimited="true" ctrlrange="-2 2"/>
  </actuator>

  <sensor>
    <jointpos name="hinge_position" joint="hinge"/>
    <jointvel name="hinge_velocity" joint="hinge"/>
    <actuatorfrc name="hinge_torque" actuator="hinge_motor"/>
  </sensor>
</mujoco>
```

这个模型的 actuator 硬限制是 ±2 N·m。示例还会使用更保守的教学限制 ±1 N·m。

## 2.6 完整程序：常值、方波和正弦力矩

将以下代码复制为 `/tmp/lesson02_torque.py`：

```python
from pathlib import Path
import argparse

import mujoco
import numpy as np


MODEL_PATH = Path("/tmp/single_hinge.xml")
TEACHING_TORQUE_LIMIT = 1.0  # N·m，比 XML 的 ±2 N·m 更保守


def command_torque(mode: str, t: float) -> float:
    """返回尚未限幅的期望力矩。"""
    if mode == "constant":
        return 0.5
    if mode == "square":
        # 每 0.5 秒翻转一次方向。
        return 0.6 if int(t / 0.5) % 2 == 0 else -0.6
    if mode == "sine":
        # 0.5 Hz 正弦波。
        return 0.8 * np.sin(2.0 * np.pi * 0.5 * t)
    raise ValueError(f"未知模式：{mode}")


def get_scalar_sensor(model: mujoco.MjModel, data: mujoco.MjData, name: str) -> float:
    sensor_id = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_SENSOR, name)
    if sensor_id < 0:
        raise KeyError(f"缺少传感器 {name}")
    if int(model.sensor_dim[sensor_id]) != 1:
        raise ValueError(f"{name} 不是标量传感器")
    return float(data.sensordata[int(model.sensor_adr[sensor_id])])


def run(mode: str, duration: float = 4.0) -> None:
    model = mujoco.MjModel.from_xml_path(str(MODEL_PATH))
    data = mujoco.MjData(model)

    joint_id = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_JOINT, "hinge")
    actuator_id = mujoco.mj_name2id(
        model, mujoco.mjtObj.mjOBJ_ACTUATOR, "hinge_motor"
    )
    if joint_id < 0 or actuator_id < 0:
        raise RuntimeError("joint 或 actuator 名称错误")

    qpos_adr = int(model.jnt_qposadr[joint_id])
    qvel_adr = int(model.jnt_dofadr[joint_id])
    xml_low, xml_high = model.actuator_ctrlrange[actuator_id]

    # 从一个非零角度释放，更容易看到重力与控制力矩共同作用。
    data.qpos[qpos_adr] = 0.4
    data.qvel[qvel_adr] = 0.0
    mujoco.mj_forward(model, data)

    times: list[float] = []
    positions: list[float] = []
    velocities: list[float] = []
    commands: list[float] = []
    measured_torques: list[float] = []

    steps = round(duration / model.opt.timestep)
    for _ in range(steps):
        raw_tau = command_torque(mode, data.time)

        # 第一层：教学限制；第二层：模型 actuator 硬限制。
        safe_tau = float(
            np.clip(raw_tau, -TEACHING_TORQUE_LIMIT, TEACHING_TORQUE_LIMIT)
        )
        safe_tau = float(np.clip(safe_tau, xml_low, xml_high))
        data.ctrl[actuator_id] = safe_tau

        mujoco.mj_step(model, data)

        q = float(data.qpos[qpos_adr])
        qd = float(data.qvel[qvel_adr])
        measured_tau = get_scalar_sensor(model, data, "hinge_torque")
        state = np.array([q, qd, safe_tau, measured_tau])
        if not np.all(np.isfinite(state)):
            raise FloatingPointError("仿真出现 NaN 或 Inf")

        times.append(float(data.time))
        positions.append(q)
        velocities.append(qd)
        commands.append(safe_tau)
        measured_torques.append(measured_tau)

    print(f"mode                  : {mode}")
    print(f"steps                 : {steps}")
    print(f"simulated time        : {times[-1]:.3f} s")
    print(f"final angle           : {positions[-1]:.4f} rad")
    print(f"max abs angle         : {np.max(np.abs(positions)):.4f} rad")
    print(f"max abs velocity      : {np.max(np.abs(velocities)):.4f} rad/s")
    print(f"max abs command       : {np.max(np.abs(commands)):.4f} N·m")
    print(f"max abs sensed torque : {np.max(np.abs(measured_torques)):.4f} N·m")
    print(
        "joint-limit contact   : "
        f"{np.max(np.abs(positions)) >= 1.5 - 1e-3}"
    )


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--mode", choices=("constant", "square", "sine"), default="constant"
    )
    parser.add_argument("--duration", type=float, default=4.0)
    args = parser.parse_args()
    if args.duration <= 0:
        parser.error("--duration 必须大于 0")
    run(args.mode, args.duration)


if __name__ == "__main__":
    main()
```

依次运行：

```bash
python /tmp/lesson02_torque.py --mode constant
python /tmp/lesson02_torque.py --mode square
python /tmp/lesson02_torque.py --mode sine
```

## 2.7 如何分析结果

### 常值力矩

关节受到恒定 actuator 力矩、重力矩、阻尼和可能的关节限位力共同作用。它不一定持续匀加速，也不会自动停在“0.5 rad”。

### 方波力矩

力矩方向每 0.5 秒翻转。角速度不会瞬间翻转，因为刚体有惯量；这正是动力学与直接修改 `qpos` 的区别。

### 正弦力矩

周期输入会产生有相位延迟的角度响应。响应幅值取决于频率、惯量、重力和阻尼。

### command 与 sensed torque

简单 `gear=1` 模型中两者通常接近，但概念不同：

- command 是你写入 `data.ctrl` 的输入；
- actuator force/sensor 是 MuJoCo 计算后的执行器输出量。

复杂传动、gear 或 actuator 类型会改变两者关系。

## 2.8 可选：只对 T800 一个关节施加小力矩

下面的完整程序只用于观察耦合效应。T800 是自由基座机器人，且其余关节为零力矩，所以它会跌倒。将代码复制为 `/tmp/lesson02_t800_single_torque.py`：

```python
from pathlib import Path

import mujoco
import numpy as np


MODEL_PATH = Path("models/t800/t800.xml").resolve()
JOINT_NAME = "J23_HEAD_PITCH"
ACTUATOR_NAME = f"motor_{JOINT_NAME}"
TEACHING_LIMIT = 0.5  # N·m，远低于模型硬上限


def main() -> None:
    model = mujoco.MjModel.from_xml_path(str(MODEL_PATH))
    data = mujoco.MjData(model)

    joint_id = mujoco.mj_name2id(
        model, mujoco.mjtObj.mjOBJ_JOINT, JOINT_NAME
    )
    actuator_id = mujoco.mj_name2id(
        model, mujoco.mjtObj.mjOBJ_ACTUATOR, ACTUATOR_NAME
    )
    if joint_id < 0 or actuator_id < 0:
        raise KeyError("joint/actuator 名称不存在")

    qadr = int(model.jnt_qposadr[joint_id])
    dadr = int(model.jnt_dofadr[joint_id])
    ctrl_low, ctrl_high = model.actuator_ctrlrange[actuator_id]

    mujoco.mj_resetData(model, data)
    mujoco.mj_forward(model, data)

    duration = 0.25  # 只观察很短时间
    steps = round(duration / model.opt.timestep)
    max_abs_q = 0.0
    max_abs_qd = 0.0

    for _ in range(steps):
        data.ctrl[:] = 0.0
        desired_tau = 0.25  # N·m
        tau = np.clip(desired_tau, -TEACHING_LIMIT, TEACHING_LIMIT)
        tau = np.clip(tau, ctrl_low, ctrl_high)
        data.ctrl[actuator_id] = tau
        mujoco.mj_step(model, data)

        q = float(data.qpos[qadr])
        qd = float(data.qvel[dadr])
        if not np.all(np.isfinite(data.qpos)) or not np.all(np.isfinite(data.qvel)):
            raise FloatingPointError("T800 状态出现 NaN 或 Inf")
        max_abs_q = max(max_abs_q, abs(q))
        max_abs_qd = max(max_abs_qd, abs(qd))

    print(f"joint         : {JOINT_NAME}")
    print(f"final q       : {data.qpos[qadr]:.6f} rad")
    print(f"final qd      : {data.qvel[dadr]:.6f} rad/s")
    print(f"max |q|       : {max_abs_q:.6f} rad")
    print(f"max |qd|      : {max_abs_qd:.6f} rad/s")
    print(f"base xyz      : {data.qpos[:3]}")
    print("注意：其余关节无控制，自由基座跌倒属于预期现象。")


if __name__ == "__main__":
    main()
```

运行：

```bash
python /tmp/lesson02_t800_single_torque.py
```

选择头部关节且使用很小力矩，是为了降低实验剧烈程度；即使如此，基座和其他关节仍受重力与反作用力影响。

## 2.9 为什么不要直接修改 `qpos` 来“控制”

以下操作只是瞬移状态：

```python
data.qpos[qadr] = target
mujoco.mj_forward(model, data)
```

它适合 reset/初始化，但不是动态控制，因为它绕过了惯量、力矩和时间演化。真正的控制流程应是：

```text
读取 q、qd → 计算 ctrl/力矩 → mj_step → 得到下一状态
```

下一章会把“目标角”通过 PD/PID 变成受限力矩。

## 2.10 常见错误

### 将 `data.ctrl` 当成目标角

当前模型是 motor actuator。写入 1.0 表示 actuator 输入，不代表目标位置 1 rad。

### 只做教学限幅，不检查 XML 限幅

应取两者交集：先按教学上限裁剪，再按 `model.actuator_ctrlrange` 裁剪。

### 用很大力矩“让效果明显”

大力矩会迅速撞击关节限位，并掩盖你真正想理解的动力学。应从小输入逐步增加。

### 用 `qpos` 差分估计速度

MuJoCo 已提供 `data.qvel`。自由基座四元数也不能直接用普通减法得到角速度。

### T800 跌倒后认为单关节索引错了

其余 24 个关节和自由基座都没有姿态控制，跌倒是必然的。先通过第 01 章程序验证映射，再分析动力学。

## 2.11 安全提示

- 所有实验先在 `/tmp/single_hinge.xml` 上进行。
- 对 T800 只使用远小于 MJCF 硬上限的教学力矩，且缩短仿真时间。
- 每步检查 NaN/Inf，并保留两层限幅。
- 本章数值不适用于真机；真机还需要急停、通信超时、姿态检查、速度/温度/电流限制等硬件保护。

## 2.12 小练习

1. 将正弦频率从 0.5 Hz 改成 1 Hz，比较最大角度。
2. 将摆的 `damping` 从 0.05 改成 0.5，观察方波响应。
3. 将初始角度改为 `-0.4` rad，判断重力初始力矩方向。
4. 把 `command_torque()` 增加为三角波，但仍保持两层限幅。
5. 将 `TEACHING_TORQUE_LIMIT` 降到 0.2 N·m，确认输出统计不超过它。
6. 思考：如果想让关节稳定跟踪某个角度，控制力矩至少应依赖哪些状态？

## 2.14 与原生 SDK 的关系

SDK 的 MuJoCo 仿真器最终也是把计算出的关节力矩写入 `d->ctrl`。区别是 SDK 不要求上层直接指定原始力矩：它接收目标位置、目标速度、Kp、Kd 和前馈力矩，然后在 [simulation/mujoco/main.cc](../engineai_robotics_native_sdk/simulation/mujoco/main.cc) 的 `TorqueController` 中计算：

```text
tau = kp * (q_des - q) + kd * (qd_des - qd) + tau_ff
```

本章掌握的是公式最右端最终产生的 `tau` 如何驱动物理模型。下一章将从目标位置推导并实现这条控制律。
